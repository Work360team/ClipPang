# ClipPang

เว็บแอปสำหรับเปลี่ยนคลิปสินค้าดิบให้พร้อมปักตะกร้า มีสคริปต์ขาย เสียงพากย์ไทย และซับคาราโอเกะใน workflow เดียว ออกแบบตาม `docs/blueprint-local.html`

## หน้าหลัก

- `/` แดชบอร์ดโปรเจกต์และสถานะงาน
- `/setup` ตัวช่วยติดตั้งครั้งแรก ตรวจระบบ, FFmpeg และ Gemini API key
- `/p/:id` ตัวช่วยสร้างคลิป 5 ขั้น: คลิป → สินค้า → เสียง → สคริปต์/ซับ → ผลลัพธ์
- `/styles` แกลเลอรีสไตล์ซับ 4 รูปแบบพร้อมวิดีโอพรีวิว
- `/settings` API key, โฟลเดอร์ทำงาน, เวอร์ชัน, privacy และแคชเสียง

## สถานะของเวอร์ชันนี้

เวอร์ชันเว็บนี้เป็น interactive product MVP: อัปโหลดและพรีวิววิดีโอในเบราว์เซอร์ได้, ทดลองเสียงผ่าน Web Speech, แก้/สร้างสคริปต์รายท่อน, ทดลอง workflow เรนเดอร์ และดาวน์โหลดไฟล์ตัวอย่าง/SRT/JSON ได้

งานเรนเดอร์ FFmpeg/HyperFrames, SQLite, Gemini TTS และการเปิดโฟลเดอร์จริงยังต้องต่อเข้ากับ Local API ตาม contract ใน blueprint ก่อนใช้ผลิตคลิปจริงบนเครื่องผู้ใช้

## พัฒนาในเครื่อง

```bash
npm install
npm run dev
npm run build
npm test
```

ต้องใช้ Node.js 22.13 ขึ้นไป ฟอนต์หน้าเว็บใช้ Kanit แบบ self-hosted ผ่าน `@fontsource/kanit`
