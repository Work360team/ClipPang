01 · ทำความรู้จัก

Clip360 คืออะไร

Clip360 เป็นเว็บแอปที่ รันอยู่บนเครื่องคุณเอง เปิดใช้ผ่านเบราว์เซอร์เหมือนเว็บทั่วไป แต่ไม่มีเซิร์ฟเวอร์กลาง ไม่มีค่าสมาชิกรายเดือน และคลิปทุกไฟล์ไม่เคยออกจากคอมพิวเตอร์ของคุณ

สิ่งที่มันทำคือรับ คลิปสินค้าดิบ ที่คุณถ่ายไว้ (ถ่ายด้วยมือถือก็ได้) แล้วเปลี่ยนเป็นวิดีโอแนวตั้ง 9:16 ที่มีเสียงพากย์ภาษาไทยและซับไตเติลขึ้นตามคำพูด พร้อมเอาไปโพสต์ปักตะกร้าได้เลย งานที่ปกติต้องเปิดโปรแกรมตัดต่อ หาคนพากย์ และพิมพ์ซับเองทีละคำ ถูกยุบเหลือ 5 ขั้นตอนบนหน้าเว็บเดียว

🔒

ไฟล์อยู่กับคุณ

เซิร์ฟเวอร์ฟังเฉพาะ 127.0.0.1 คลิปและไฟล์ผลลัพธ์ไม่ถูกอัปโหลดออกไปไหน มีแต่ข้อความสินค้าและสคริปต์เท่านั้นที่ส่งไปให้ AI ตอนสร้างเสียงหรือเขียนสคริปต์

💸

ไม่มีค่ารายเดือน

ตัวโปรแกรมไม่คิดเงิน ค่าใช้จ่ายเดียวคือ Gemini API ซึ่งมีโควตาฟรีให้ใช้ทุกวัน คลิปหนึ่งตัวถ้าจ่ายจริงตกราว ฿0.15

🎙️

เสียงไทย 30 เสียง

เลือกได้ทั้งเสียงชาย 16 เสียงและหญิง 14 เสียง ฟังตัวอย่างก่อนเลือกได้โดยไม่เปลืองโควตา

✍️

ซับตรงคำพูด

ซับขึ้นตามจังหวะเสียงจริง ไม่ใช่กะเอา เลือกได้ 15 สไตล์ และวางไว้ด้านบน กลาง หรือล่างของจอ

เหมาะกับใครคนขายของออนไลน์ที่ถ่ายคลิปสินค้าเองแล้วต้องทำวิดีโอโพสต์บ่อย ๆ โดยเฉพาะ TikTok Shop — ไม่ต้องมีพื้นฐานตัดต่อ แต่ต้องพอกดใช้คอมพิวเตอร์ได้
02 · ปัญหาที่มันแก้

ก่อนมี Clip360 ต้องเจออะไรบ้าง

คลิปหนึ่งตัวที่ดู "ธรรมดามาก" จริง ๆ แล้วกินเวลาไปหลายอย่างพร้อมกัน

ตัดต่อเองทีละคลิปเปิดโปรแกรมตัดต่อ ลากไทม์ไลน์ ตัดหัวตัดท้าย กว่าจะได้ 30 วินาทีก็หมดไปครึ่งชั่วโมง
ไม่กล้าพากย์เองจะจ้างคนพากย์ก็มีค่าใช้จ่ายต่อคลิป จะพากย์เองก็ไม่มั่นใจเสียงตัวเอง
พิมพ์ซับทีละคำซับต้องตรงกับที่พูด ไม่งั้นดูแล้วขัดตา การไล่จับเวลาเองคืองานที่น่าเบื่อที่สุด
คิดสคริปต์ขายไม่ออกรู้ว่าสินค้าดียังไง แต่เรียบเรียงเป็นคำพูด 30 วินาทีที่คนดูจบไม่ถูก

Clip360 ทำอะไรให้ได้บ้าง

ความสามารถรายละเอียด
รวมหลายคลิปเป็นตัวเดียวอัปโหลดพร้อมกันได้สูงสุด 12 ไฟล์ ลากเรียงลำดับ ตัดหัวท้าย แยกคลิป และลบช่วงที่ไม่เอาได้บน Timeline (สูงสุด 24 ช่วง รวมไม่เกิน 60 วินาที)
ช่วยเขียนสคริปต์ขายกรอกรายละเอียดสินค้า แล้วให้ AI ร่างสคริปต์พากย์ให้ แก้ไขเองทีหลังได้ทุกประโยค
พากย์เสียงไทย30 เสียงจาก Gemini TTS ปรับความเร็วและโทนได้ ฟังตัวอย่างทุกเสียงได้ฟรีก่อนเลือก
ใส่ซับตามคำพูด15 สไตล์ — 3 สไตล์พื้นฐาน (เร็ว) และ 12 สไตล์พรีเมียมแบบมีอนิเมชัน เลือกตำแหน่งบน/กลาง/ล่างได้
สร้างจบในครั้งเดียวตรวจสรุปงานแล้วกดสร้าง ได้ไฟล์คุณภาพเต็มพร้อมโพสต์เลย ไม่ต้องเรนเดอร์ร่างก่อน
แคปชั่นสำหรับโพสต์ระบบร่างแคปชั่นพร้อมแฮชแท็กให้อัตโนมัติตั้งแต่คลิปเสร็จ ก๊อปไปวางได้เลย
ไฟล์ครบชุดได้ MP4 พร้อมโพสต์ บวกไฟล์ซับ SRT/ASS ภาพปก และไฟล์เสียง เผื่อเอาไปแก้ต่อในโปรแกรมอื่น
03 · เตรียมตัว

สิ่งที่ต้องมีก่อนติดตั้ง

มีอยู่อย่างเดียวที่ต้องลงเองก่อน ที่เหลือ Clip360 จัดการให้ทั้งหมด

1️⃣

Node.js 22.13 ขึ้นไป

ต้องลงเอง — โหลดจาก nodejs.org เลือกตัว LTS กด Next รัว ๆ จนจบ ตัวนี้คือเครื่องยนต์ที่ทำให้ Clip360 รันได้

2️⃣

FFmpeg

ไม่ต้องลงเอง — Clip360 มีปุ่มติดตั้งให้ในหน้าตั้งค่า กดปุ่มเดียวจบ ตัวนี้คือโปรแกรมที่ทำงานตัดต่อจริง ๆ เบื้องหลัง

3️⃣

Gemini API key

ขอฟรี — ใช้บัญชี Google ขอที่ Google AI Studio ไม่ต้องผูกบัตร ตัวนี้คือกุญแจสำหรับสร้างเสียงพากย์

💻

เครื่องคอมพิวเตอร์

Windows, macOS หรือ Linux ก็ได้ · พื้นที่ว่างสัก 5 GB สำหรับคลิปและไฟล์ผลลัพธ์ · การเรนเดอร์ใช้ CPU ค่อนข้างหนัก เครื่องแรงจะเสร็จไวกว่า

ยังไม่ต้องกังวลเรื่อง Gemini key ตอนนี้ติดตั้งให้เปิดโปรแกรมได้ก่อน แล้วค่อยขอ key ทีหลังก็ได้ — หน้าตั้งค่าจะบอกเองว่ายังขาดอะไร
04 · ติดตั้ง

ติดตั้งและเปิดโปรแกรม

ครั้งแรกจะช้าหน่อยเพราะต้องโหลดส่วนประกอบ (ราว 3–10 นาทีแล้วแต่เน็ต) ครั้งต่อ ๆ ไปเปิดได้ในไม่กี่วินาที

1
ลง Node.js ก่อน
เข้า nodejs.org โหลดตัว LTS แล้วติดตั้งตามปกติ
💡อยากเช็กว่าลงสำเร็จไหม เปิด Terminal (Mac) หรือ Command Prompt (Windows) พิมพ์ node -v ถ้าขึ้นเลขเวอร์ชัน 22 ขึ้นไปคือใช้ได้
2
โหลดไฟล์โปรแกรมจาก GitHub
ตัวโปรแกรมอยู่ที่ github.com/Work360team/Clip360 โหลดได้สองวิธี เลือกอย่างใดอย่างหนึ่ง
  • วิธีง่ายที่สุด — โหลดเป็นไฟล์ ZIP กดปุ่มเขียว Code บนหน้า GitHub แล้วเลือก Download ZIP หรือกด ลิงก์นี้ ได้เลย จากนั้นแตกไฟล์ออกมา
  • ถ้าใช้ git เป็น สั่ง git clone https://github.com/Work360team/Clip360.git วิธีนี้อัปเดตเวอร์ชันใหม่ทีหลังได้ด้วยคำสั่งเดียว
📦โฟลเดอร์ที่แตกจาก ZIP จะชื่อ Clip360-main เปลี่ยนชื่อเป็น Clip360 เฉย ๆ ก็ได้ ไม่มีผลอะไร
3
วางโฟลเดอร์ไว้ที่ที่จำได้
ย้ายโฟลเดอร์ที่แตกออกมาไปไว้ที่ไหนก็ได้ที่คุณมีสิทธิ์เขียนไฟล์ เช่น D:\Clip360 หรือใน Documents
  • อย่าวางไว้ใน Program Files หรือโฟลเดอร์ระบบ เพราะโปรแกรมต้องเขียนไฟล์ผลลัพธ์ลงในโฟลเดอร์ตัวเอง
  • ถ้าวางไว้บน OneDrive/Google Drive ที่ซิงก์ตลอด อาจช้าและชนกันได้ แนะนำให้วางในไดรฟ์ปกติ
4
เปิดโปรแกรม
เลือกตามระบบปฏิบัติการที่ใช้

ดับเบิลคลิกไฟล์ เริ่มโปรแกรม.bat ในโฟลเดอร์ Clip360

🛡️ถ้า Windows ขึ้นหน้าจอฟ้า "Windows protected your PC" ให้กด More info → Run anyway — เกิดเพราะไฟล์ไม่ได้เซ็นดิจิทัล ไม่ใช่เพราะมีไวรัส

ครั้งแรกเปิด Terminal ที่โฟลเดอร์นี้แล้วรันคำสั่งนี้หนึ่งครั้ง

chmod +x start.command start.sh
./start.command

หลังจากนั้นดับเบิลคลิก start.command ได้เลย

chmod +x start.sh
./start.sh
⚙️ตัวเปิดโปรแกรมจะตรวจ Node ให้เอง ติดตั้งส่วนประกอบที่ขาด แล้วเปิดเบราว์เซอร์ไปที่ http://127.0.0.1:4321 อัตโนมัติ — ถ้าพอร์ตนั้นมีคนใช้อยู่ ระบบจะเลื่อนไปพอร์ตถัดไปและบอก URL จริงในหน้าต่างดำ
5
อย่าปิดหน้าต่างดำ
หน้าต่างสีดำที่เด้งขึ้นมาคือตัวโปรแกรมเอง ถ้าปิดหน้าต่างนั้น เว็บจะใช้ไม่ได้ทันที ให้ย่อเก็บไว้แทน
🔚เลิกใช้งานเมื่อไหร่ ค่อยปิดหน้าต่างดำเพื่อปิดโปรแกรม งานที่เรนเดอร์ค้างอยู่จะหยุดไปด้วย
อัปเดตเป็นเวอร์ชันใหม่ทีหลัง ถ้าโหลดมาเป็น ZIP ให้โหลดใหม่แล้วเอาไฟล์ทับของเดิม — โฟลเดอร์ data/, input/, projects/ และไฟล์ .env เป็นของคุณ ไม่มีอยู่ในไฟล์ที่โหลดมา จึงไม่ถูกทับ · ถ้าใช้ git ให้สั่ง git pull ในโฟลเดอร์นั้น แล้วเปิดโปรแกรมตามปกติ ตัวเปิดโปรแกรมจะ build ใหม่ให้เอง
05 · ตั้งค่าครั้งแรก

ตั้งค่าครั้งแรก ทำครั้งเดียวจบ

เปิดเว็บได้แล้วยังใช้งานไม่ได้ทันที ต้องเติมสองอย่างนี้ก่อน

1
ติดตั้ง FFmpeg จากในเว็บ
ไปที่เมนู ตั้งค่า (หรือ ศูนย์ช่วยเหลือการติดตั้ง มุมล่างซ้าย) ระบบจะตรวจให้เองว่ามี FFmpeg แล้วหรือยัง ถ้ายังไม่มีจะมีปุ่มติดตั้งให้กด
  • Clip360 จะโหลดตัวติดตั้งที่ถูกต้องตามระบบปฏิบัติการให้เอง แล้วเก็บไว้ในโฟลเดอร์ตัวเอง ไม่ไปยุ่งกับที่อื่นในเครื่อง
  • ใช้เวลาราว 1–3 นาที ระหว่างนั้นจะเห็นแถบความคืบหน้า
💡FFmpeg คือเครื่องมือตัดต่อวิดีโอที่ทำงานเบื้องหลัง ทุกอย่างที่เกี่ยวกับการรวมคลิป ใส่เสียง และเผาซับลงวิดีโอ ใช้ตัวนี้ทั้งหมด
2
ขอ Gemini API key แล้ววางในหน้าตั้งค่า
เข้า Google AI Studio ล็อกอินด้วยบัญชี Google กด Create API key แล้วคัดลอกมาวางในช่องของหน้าตั้งค่า
  • key จะถูกบันทึกลงไฟล์ .env ในโฟลเดอร์โปรแกรม ไม่ได้ส่งไปเก็บที่ไหน
  • ใส่ได้หลายใบ ถ้าใบหนึ่งใช้ครบโควตาวันนั้น ระบบจะสลับไปใบถัดไปให้เอง
  • กด ฟังเสียงทดสอบ เพื่อดูว่า key ใช้ได้จริง (ใช้โควตา 1 คำขอ)
🔑อยากได้โควตาเพิ่ม ต้องสร้าง key จาก คนละโปรเจกต์ Google Cloud — สร้างหลาย key ในโปรเจกต์เดียวกันใช้โควตาก้อนเดียวกัน ไม่ได้เพิ่มอะไร
3
เช็กว่าพร้อมแล้ว
ในหน้าตั้งค่าจะมีการ์ดสรุปสถานะ ถ้าขึ้นว่า "เครื่องนี้พร้อมทำคลิปแล้ว" ครบทั้งสามข้อ (ตัดต่อวิดีโอ / เสียงพากย์ / ผู้ช่วยเขียนสคริปต์) แปลว่าเริ่มใช้งานได้

07 · ข้อมูลของคุณ

ไฟล์ทุกอย่างเก็บไว้ที่ไหน

ทั้งหมดอยู่ในโฟลเดอร์ Clip360 บนเครื่องคุณ ไม่มีอะไรอยู่บนคลาวด์ — สำรองข้อมูลคือก๊อปโฟลเดอร์นี้ทั้งอัน

ตำแหน่งเก็บอะไร
projects/<id>/out/ผลงานที่เสร็จแล้ว — MP4, ภาพปก, ไฟล์เสียง, SRT, ASS และรายงานการเรนเดอร์
input/คลิปดิบที่นำเข้ามา (ก๊อปไฟล์มาวางที่นี่เองก็ได้)
data/clip360.dbรายการโปรเจกต์และสถานะคิวงาน
data/trash/โปรเจกต์ที่ลบไปแล้ว — ยังกู้กลับเองได้ ไม่ได้ลบถาวรทันที
.envAPI key และรหัสผ่านสำหรับเข้าจากเครื่องอื่น ไฟล์นี้ห้ามส่งให้ใคร
data/cache/แคชเสียง ประโยคเดิมที่เคยสร้างแล้วจะไม่ยิงซ้ำ ช่วยประหยัดโควตา
ย้ายเครื่องหรือสำรองข้อมูลก๊อปทั้งโฟลเดอร์ Clip360 ไปเครื่องใหม่ที่มี Node.js แล้วเปิดตัวเริ่มโปรแกรมได้เลย โปรเจกต์เก่ามาครบ ไม่ต้องตั้งค่าใหม่
08 · โควตาและค่าใช้จ่าย

ต้องจ่ายเท่าไหร่

ตัวโปรแกรมฟรี ค่าใช้จ่ายอย่างเดียวคือการสร้างเสียงพากย์ผ่าน Gemini ซึ่งมีโควตาฟรีให้อยู่แล้ว

🆓

แบบฟรี

Gemini มีโควตาฟรีต่อ key ต่อวัน รีเซ็ตทุกวัน ทำคลิปเล่น ๆ วันละไม่กี่ตัวมักไม่ต้องจ่ายเลย ถ้าโควตาหมดให้รอวันถัดไป หรือเพิ่ม key จากคนละโปรเจกต์

💳

แบบจ่ายเงิน

เปิด billing กับ Google แล้วโควตาจะกว้างขึ้นมาก คลิป 30 วินาทีตกราว ฿0.15 ต่อคลิป — ถ้าทำวันละหลายตัว วิธีนี้คุ้มและไม่ต้องคอยสลับหลายบัญชี

📊

ดูโควตาตัวเอง

หน้าตั้งค่ามีการ์ด โควตาของฉัน บอกว่าวันนี้ใช้ไปกี่คำขอ เหลือเท่าไหร่ กำลังใช้ key ชุดไหน และสถิติย้อนหลัง 7 วัน

♻️

ประหยัดโควตา

ฟังตัวอย่างเสียงไม่เสียโควตา · ประโยคที่เคยสร้างเสียงแล้วจะถูกใช้ซ้ำจากแคช · ตรวจสคริปต์ให้เรียบร้อยก่อนกดสร้าง จะได้ไม่ต้องสร้างเสียงซ้ำ

ราคาอ้างอิงตัวเลขข้างบนคำนวณจากราคา Gemini API ณ สิงหาคม 2026 ควรเช็กหน้า pricing ของ Google อีกครั้งก่อนใช้งานปริมาณมาก
09 · ใช้งานขั้นสูง

ใช้จากมือถือ และแบ่งให้คนอื่นใช้

ปกติ Clip360 เปิดได้เฉพาะบนเครื่องที่รันโปรแกรมเท่านั้น ซึ่งปลอดภัยที่สุด — แต่ถ้าอยากเปิดจากมือถือหรือให้ทีมใช้ด้วย ก็ทำได้

A
เปิดให้เข้าจากเครื่องอื่นได้
ต้องตั้งชื่อผู้ใช้กับรหัสผ่านก่อน แล้วระบุว่าอนุญาตให้เข้าผ่านชื่อโดเมนไหน
# ตั้งชื่อผู้ใช้และรหัสผ่าน (เก็บเป็น hash ไม่ใช่รหัสตรง ๆ)
node scripts/set-password.mjs ชื่อผู้ใช้ รหัสผ่าน

# แล้วเพิ่มบรรทัดนี้ใน .env — ใส่โดเมนที่คุณชี้มาที่เครื่องนี้
CLIP360_ALLOWED_HOSTS=clip360.example.com
🔐ต้องครบทั้งสามอย่าง (ชื่อผู้ใช้ + รหัสผ่าน + โดเมนที่อนุญาต) ระบบถึงจะยอมรับคำขอจากเครื่องอื่น ถ้าขาดอย่างใดอย่างหนึ่งจะยังล็อกไว้ที่เครื่องตัวเองเหมือนเดิม
B
เพิ่มบัญชีให้คนในทีม
เจ้าของระบบเพิ่มบัญชีได้จากการ์ด บัญชีผู้ใช้ ในหน้าตั้งค่า แต่ละคนจะเห็นเฉพาะโปรเจกต์ของตัวเอง
  • แต่ละคนใส่ Gemini key ของตัวเองได้ โควตาจะแยกกันจริง ไม่แย่งกันใช้
  • ผู้ใช้เปลี่ยนรหัสผ่านตัวเองได้จากการ์ด บัญชีของฉัน ไม่ต้องรอเจ้าของ
  • เปลี่ยนรหัสเมื่อไหร่ เครื่องอื่นที่ค้างล็อกอินอยู่จะหลุดทั้งหมดทันที
C
ลองใช้โดยไม่ต้องมี Gemini key
อยากลองระบบก่อนขอ key ใช้โหมดทดสอบได้ — จะได้สคริปต์แบบเทมเพลตและเสียง "ตู๊ด" แทนเสียงพูดจริง แต่เห็นภาพว่าทุกอย่างทำงานยังไง
npm run local:mock
ข้อควรระวังการเปิดให้เข้าจากเครื่องอื่นหมายถึงเปิดเครื่องคุณสู่เครือข่ายภายนอก ควรใช้รหัสผ่านที่เดายาก และอย่าแชร์ไฟล์ .env ให้ใครเด็ดขาดเพราะในนั้นมี API key อยู่
