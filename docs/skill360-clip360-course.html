Clip360 — คลิปปักตะกร้า ไม่มีค่ารายเดือน

คลิปสินค้าที่ถ่ายค้างไว้ในมือถือ กับวิดีโอที่พร้อมปักตะกร้า ห่างกันแค่โปรแกรมตัวเดียวที่รันอยู่บนเครื่องคุณเอง — คอร์สนี้พาไปตั้งแต่ยังไม่มีอะไรเลย จนได้ไฟล์ MP4 ที่โพสต์ได้จริง

1คอร์สนี้เหมาะกับใคร

คนขายของออนไลน์ที่ถ่ายคลิปสินค้าเองแล้วต้องทำวิดีโอโพสต์บ่อย ๆ โดยเฉพาะ TikTok Shop ไม่ต้องมีพื้นฐานตัดต่อ ขอแค่พอกดใช้คอมพิวเตอร์ได้

ถามตัวเอง: เดือนที่แล้วมีคลิปกี่ตัวที่ถ่ายไว้แล้วไม่ได้โพสต์ เพราะยังไม่ได้ตัดต่อ?

2จบคอร์สแล้วทำอะไรได้

ติดตั้งโปรแกรมเองได้ ต่อ API key เองได้ และทำคลิปแนวตั้งพร้อมเสียงพากย์ไทยกับซับตามคำพูดได้เองตั้งแต่ต้นจนจบ พร้อมรู้ว่าถ้าพังตรงไหนต้องแก้ยังไง

💡 หลักคิดของคอร์สนี้

Clip360 ไม่ใช่เว็บที่คุณสมัครสมาชิกแล้วอัปโหลดคลิปขึ้นไป มันคือโปรแกรมที่รันอยู่บนเครื่องคุณ แล้วเปิดใช้ผ่านเบราว์เซอร์ ทุกอย่างที่เรียนในคอร์สนี้จึงเริ่มจากคำถามเดียว — เครื่องของคุณพร้อมหรือยัง

A

บทที่ 01 · ทำความรู้จัก ⏱ 5 นาที

Clip360 คืออะไร ทำอะไรได้บ้าง

งานที่ปกติต้องเปิดโปรแกรมตัดต่อ หาคนพากย์ และพิมพ์ซับเองทีละคำ ถูกยุบเหลือ 5 ขั้นตอนบนหน้าเว็บเดียวที่รันอยู่บนเครื่องคุณ

Clip360 รับคลิปสินค้าดิบที่คุณถ่ายไว้ (ถ่ายด้วยมือถือก็ได้) แล้วเปลี่ยนเป็นวิดีโอแนวตั้ง 9:16 ที่มีเสียงพากย์ภาษาไทยและซับไตเติลขึ้นตามคำพูด พร้อมเอาไปโพสต์ปักตะกร้าได้เลย

🔒ไฟล์อยู่กับคุณ

เซิร์ฟเวอร์ฟังเฉพาะเครื่องตัวเอง คลิปและไฟล์ผลลัพธ์ไม่ถูกอัปโหลดออกไปไหน มีแต่ข้อความสินค้าและสคริปต์เท่านั้นที่ส่งไปให้ AI ตอนสร้างเสียง

💸ไม่มีค่ารายเดือน

ตัวโปรแกรมไม่คิดเงิน ค่าใช้จ่ายเดียวคือ Gemini API ซึ่งมีโควตาฟรีให้ใช้ทุกวัน

🎙️เสียงไทย 30 เสียง

ชาย 16 หญิง 14 ฟังตัวอย่างก่อนเลือกได้โดยไม่เปลืองโควตา

✍️ซับตรงคำพูด

ซับขึ้นตามจังหวะเสียงจริง ไม่ใช่กะเอา เลือกได้ 15 สไตล์ และวางบน กลาง หรือล่างของจอ

บทที่ 02 · เตรียมตัว ⏱ 6 นาที

เตรียมเครื่องและติดตั้ง

มีของอยู่สามอย่างที่ต้องมี แต่ต้องลงเองแค่อย่างเดียว — ที่เหลือ Clip360 จัดการให้ในหน้าเว็บของตัวเอง

1Node.js 22.13+

ต้องลงเอง โหลดตัว LTS จาก nodejs.org กด Next รัว ๆ จนจบ นี่คือเครื่องยนต์ที่ทำให้ Clip360 รันได้

2FFmpeg

ไม่ต้องลงเอง Clip360 มีปุ่มติดตั้งให้ในหน้าตั้งค่า กดปุ่มเดียวจบ นี่คือตัวที่ทำงานตัดต่อจริงเบื้องหลัง

3Gemini API key

ขอฟรี ด้วยบัญชี Google ที่ Google AI Studio ไม่ต้องผูกบัตร นี่คือกุญแจสำหรับสร้างเสียงพากย์

💡 ยังไม่ต้องรีบขอ key

ติดตั้งให้เปิดโปรแกรมขึ้นมาได้ก่อน แล้วค่อยขอ key ทีหลังก็ได้ หน้าตั้งค่าจะบอกเองว่ายังขาดอะไรอยู่

ขั้นตอนติดตั้ง

1

ลง Node.js ก่อน

เข้า nodejs.org โหลดตัว LTS แล้วติดตั้งตามปกติ เช็กว่าสำเร็จได้ด้วยการเปิด Terminal หรือ Command Prompt แล้วพิมพ์ node -v ถ้าขึ้นเลข 22 ขึ้นไปคือใช้ได้

2

โหลดไฟล์โปรแกรมจาก GitHub

ตัวโปรแกรมอยู่ที่ github.com/Work360team/ClipPang — กดปุ่มเขียว Code → Download ZIP แล้วแตกไฟล์ หรือถ้าใช้ git เป็นก็สั่ง git clone https://github.com/Work360team/ClipPang.git ซึ่งอัปเดตทีหลังง่ายกว่าด้วย git pull

3

วางโฟลเดอร์ไว้ที่ที่จำได้

โฟลเดอร์จาก ZIP จะชื่อ Clip360-main เปลี่ยนชื่อได้ตามใจ แล้วย้ายไปไว้เช่น D:\Clip360 หรือใน Documents — อย่าวางใน Program Files หรือโฟลเดอร์ระบบ เพราะโปรแกรมต้องเขียนไฟล์ผลลัพธ์ลงในโฟลเดอร์ตัวเอง และอย่าวางบนโฟลเดอร์ที่ซิงก์คลาวด์ตลอดเวลา

4

เปิดโปรแกรมตามระบบที่ใช้

Windows ดับเบิลคลิก เริ่มโปรแกรม.bat · macOS ครั้งแรกรัน chmod +x start.command start.sh แล้ว ./start.command จากนั้นดับเบิลคลิกได้เลย · Linux รัน chmod +x start.sh แล้ว ./start.sh

5

อย่าปิดหน้าต่างดำ

หน้าต่างสีดำที่เด้งขึ้นมาคือตัวโปรแกรมเอง ปิดเมื่อไหร่เว็บใช้ไม่ได้ทันที ให้ย่อเก็บไว้ — เลิกใช้งานค่อยปิดเพื่อปิดโปรแกรม

บทที่ 03 · ตั้งค่า ⏱ 5 นาที

ตั้งค่าครั้งแรก ทำครั้งเดียวจบ

เปิดเว็บได้แล้วยังใช้งานไม่ได้ทันที ต้องเติมสองอย่างก่อน แล้วจะไม่ต้องกลับมายุ่งกับมันอีกเลย

1

ติดตั้ง FFmpeg จากในเว็บ

ไปที่เมนู ตั้งค่า หรือ ศูนย์ช่วยเหลือการติดตั้ง มุมล่างซ้าย ระบบตรวจให้เองว่ามีหรือยัง ถ้ายังไม่มีจะมีปุ่มติดตั้งให้กด ใช้เวลาราว 1–3 นาที ตัวติดตั้งถูกเก็บไว้ในโฟลเดอร์ Clip360 เอง ไม่ไปยุ่งกับที่อื่นในเครื่อง

2

ขอ Gemini API key แล้ววาง

เข้า Google AI Studio ล็อกอินด้วยบัญชี Google กด Create API key แล้วคัดลอกมาวางในหน้าตั้งค่า key จะถูกบันทึกลงไฟล์ .env ในโฟลเดอร์โปรแกรม ไม่ได้ส่งไปเก็บที่ไหน

3

เช็กว่าพร้อมแล้ว

ในหน้าตั้งค่ามีการ์ดสรุปสถานะ ถ้าขึ้นว่า "เครื่องนี้พร้อมทำคลิปแล้ว" ครบทั้งสามข้อ (ตัดต่อวิดีโอ / เสียงพากย์ / ผู้ช่วยเขียนสคริปต์) แปลว่าเริ่มได้

🔑 เรื่อง key ที่ต้องรู้ตั้งแต่วันแรก

ใส่ key ได้หลายใบ ถ้าใบหนึ่งใช้ครบโควตาวันนั้น ระบบจะสลับไปใบถัดไปให้เอง แต่ key ที่จะเพิ่มโควตาได้จริงต้องมาจากคนละโปรเจกต์ Google Cloud — สร้างหลาย key ในโปรเจกต์เดียวกันใช้โควตาก้อนเดียวกัน ไม่ได้เพิ่มอะไรเลย

💡 ทดสอบก่อนใช้จริง

กดปุ่ม ฟังเสียงทดสอบ ในหน้าตั้งค่าเพื่อดูว่า key ใช้ได้จริง (ใช้โควตา 1 คำขอ) ดีกว่าไปรู้ตอนสร้างคลิปจริงแล้วพัง

บทที่ 04 · ลงมือทำ ⏱ 6 นาที

ขั้นที่ 1 · คลิปและ Timeline

ขั้นตอนนี้ตัดสินว่าคลิปจะน่าดูหรือไม่มากกว่าทุกขั้นที่เหลือรวมกัน เพราะภาพคือสิ่งแรกที่คนเห็นก่อนจะได้ยินเสียงพากย์ด้วยซ้ำ

📥รับได้

สูงสุด 12 ไฟล์พร้อมกัน (MP4, MOV, WebM ไฟล์ละไม่เกิน 500 MB) หรือก๊อปไปวางในโฟลเดอร์ input/ ก็เห็นเหมือนกัน

✂️Timeline

สูงสุด 24 ช่วง ความยาวรวมไม่เกิน 60 วินาที ลากสลับลำดับ ตัดหัวท้าย แยกคลิป และลบช่วงที่ไม่เอาได้

♻️Media Bin

คลิปต้นฉบับยังอยู่เสมอ ลบช่วงออกจาก Timeline แล้วกดเพิ่มกลับได้ ไม่ต้องอัปโหลดใหม่

💡 ทำไมจำกัด 60 วินาที

เพราะคลิปปักตะกร้าที่คนดูจนจบมักสั้น และเสียงพากย์ที่ยาวกว่านี้จะฟังเหมือนอ่านสเปกสินค้ามากกว่าชวนซื้อ ข้อจำกัดนี้บังคับให้ตัดเหลือเฉพาะช็อตที่ขายจริง ซึ่งเป็นสิ่งที่คนทำคลิปเองมักไม่กล้าทำ
