รันให้ขึ้นก่อน

git clone https://github.com/Work360team/ClipPang.git แล้วเปิด เริ่มโปรแกรม.bat (mac ใช้ start.command) launcher จะ npm install + build + เปิด 127.0.0.1:4321 ให้เอง

ลองโดยไม่ต้องมี API key

npm run local:mock ได้สคริปต์เทมเพลตกับเสียงตู๊ดแทนของจริง เดินครบทั้ง pipeline โดยไม่กินโควตา ใช้ตอนพัฒนาเป็นหลัก

รันเทสต์ก่อนแตะโค้ด

npm run test:local คลุม store, security, API/queue, pipeline และ mock render · npm test เป็น build จริงกับ rendered HTML · ทั้งสองชุดต้องเขียวก่อน push

แผนที่โค้ด: app/ หน้าเว็บ React · server/ Local API, คิว, ฐานข้อมูล, auth · pipeline/ งานหนักทั้งหมด (TTS, ซับ, FFmpeg) · scripts/ เครื่องมือบรรทัดคำสั่ง · ข้อมูลผู้ใช้อยู่ที่ data/ กับ projects/ ซึ่ง gitignore ไว้แล้ว

หยิบตามลำดับนี้

สามข้อแรกเรียงตามผลกระทบต่อผู้ใช้วันนี้ ทำได้ทีละข้อโดยไม่ต้องรอกัน

ลำดับ 1–3 · กระทบผู้ใช้ตอนนี้

1 · ยังไม่มี
ทำให้โควตาจำสถานะข้ามการรีสตาร์ต

อาการ: pipeline/tts-quota.mjs เก็บ state ว่า key ใบไหนโดน 429 ไว้ใน Map ในหน่วยความจำ เปิดโปรแกรมใหม่แล้วระบบไปลองยิงคีย์ที่เต็มอยู่ซ้ำ ผู้ใช้ต้องนั่งรอ timeout ฟรี ๆ · เสร็จเมื่อ: ปิดแล้วเปิดโปรแกรมใหม่ ระบบยังข้ามคีย์ที่เต็มไปใบถัดไปได้ทันที

2 · ยังไม่มี
รวมคำขอ TTS หลายท่อนเป็นก้อนเดียว

อาการ: pipeline/tts.mjs ยิงหนึ่งคำขอต่อหนึ่งประโยค คลิป 30 วินาทีใช้ราว 9 คำขอ โควตาฟรีจึงหมดเร็วมาก · เสร็จเมื่อ: คลิปความยาวเท่าเดิมใช้คำขอน้อยลงอย่างมีนัย โดยเสียงแต่ละท่อนยังตัดตรงตำแหน่งเดิมและแคชยังใช้ได้

3 · พอรับได้
เข้ารหัสคีย์ของผู้ใช้ก่อนเก็บ

อาการ: ตาราง user_keys ใน server/store/sqlite-store.mjs เก็บคีย์เป็น plaintext ตอนนี้ยังพอรับได้เพราะฐานข้อมูลอยู่บนเครื่องเจ้าของเอง ไม่ต่างจาก .env · แต่ต้องแก้ก่อนขึ้นคลาวด์ ห้ามข้าม

ทำเป็นสองขยับ อย่ารื้อทีเดียว

ขยับที่ 1
ย้ายสถานะออกจากเครื่อง แต่ยังรันตัวเดียว

เปลี่ยนที่เก็บไฟล์เป็น object storage และฐานข้อมูลเป็น Postgres โดยยังรันโปรเซสเดียวเหมือนเดิม · ขยับนี้ไม่แตะ pipeline เลย และทดสอบได้ด้วยของที่มีอยู่

ขยับที่ 2
แยก worker ออกจากเว็บ

พอเรนเดอร์ไม่ได้อยู่โปรเซสเดียวกับเว็บแล้ว คิวในหน่วยความจำจะใช้ไม่ได้ทันที บังคับให้ต้องเป็นคิวจริงไปเอง · ทำขยับนี้ก่อนขยับแรกไม่ได้ เพราะ worker คนละเครื่องอ่าน SQLite กับดิสก์ของเว็บไม่ถึง

ตัวเลขที่กำหนดราคา ไม่ใช่ค่า AI — เสียงพากย์ตกราว ฿0.15 ต่อคลิป ถูกจนแทบไม่ต้องคิด แต่การเรนเดอร์กิน CPU เต็มเครื่อง 1–3 นาทีต่อคลิป และสไตล์พรีเมียมนานกว่านั้นอีกหลายเท่า

บนคลาวด์ต้นทุนจริงคือนาที CPU ของ worker ไม่ใช่จำนวนคลิป · ถ้าตั้งราคาเหมาต่อคลิปโดยไม่แยกสไตล์ คนที่เลือกพรีเมียมทุกครั้งจะกลายเป็นลูกค้าที่ขาดทุน ควรวัดเวลา CPU ต่อสไตล์จริงก่อนตั้งราคา
