แอปนี้ตอบคำถามสองข้อของสัปดาห์ที่ 2 — รันบน Plesk แล้วกดปุ่มตามลำดับ

01 · ENVIRONMENTNode รันอยู่จริงและอยู่หลังอะไร

ถ้าเห็น header ขึ้นต้นด้วย x- แปลว่ามี proxy คั่นอยู่ ซึ่งเป็นตัวที่จะ buffer SSE

ยังไม่ได้ตรวจ

02 · SSEPassenger ปล่อย stream ผ่านหรือ buffer ไว้

เซิร์ฟเวอร์ส่ง event ทุก 1 วินาที 12 ครั้ง ถ้าแท่งเรียงห่างเท่า ๆ กัน = ใช้ SSE ได้ ถ้าแท่งกระจุกท้าย = โดน buffer ต้องเปลี่ยนไปใช้ polling ทั้งระบบ

แต่ละแท่ง = ระยะห่างจาก event ก่อนหน้า (สูง = ห่างมาก)
ยังไม่ได้ทดสอบ

03 · REDISPlesk ต่อ Redis บน VPS worker ได้ไหม

ข้อนี้พังบ่อยที่สุดเพราะ ufw ยังไม่เปิดให้ IP ของ Plesk หรือลืมตั้ง requirepass ถ้าข้อนี้ไม่ผ่าน API จะสั่งงาน worker ไม่ได้เลย 

ยังไม่ได้ทดสอบ
